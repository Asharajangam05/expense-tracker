# 💰 Expense Tracker

A responsive Expense Tracker web application developed using HTML, CSS, and JavaScript. It helps users record income and expenses, calculate their balance, and manage transaction history.

## 🚀 Features

* Add income transactions
* Add expense transactions
* Calculate total income
* Calculate total expenses
* Calculate available balance
* Add transaction categories
* Add transaction date
* Search transactions
* Filter by income or expense
* Filter by category
* Delete transactions
* Data persistence using LocalStorage
* Responsive design
* Input validation
* Mobile-friendly interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* DOM Manipulation
* LocalStorage

## ⚙️ How to Run

1. Download or clone the repository.
2. Open the `Expense-Tracker` folder.
3. Open `index.html` in a web browser.
4. Enter a transaction description.
5. Enter the amount.
6. Select Income or Expense.
7. Select a category.
8. Select the date.
9. Click **Add Transaction**.

## 💾 Data Storage

The application uses browser **LocalStorage** to save transaction data.

This means transactions remain available even after refreshing or closing the browser, as long as the browser's LocalStorage data has not been cleared.
